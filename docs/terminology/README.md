# docs/terminology/

Назначение: терминологический слой пакета документации продукта.

## Артефакты

- `glossary.md` — реестр рабочих терминов Product Unit.

## Граница

- `docs/terminology/` хранит значения терминов, допустимые aliases, область применения и связанные артефакты.
- Правила выбора, изменения и проверки терминов находятся в `sops/terminology.md`.
- Журнальные факты терминологических замен находятся в `logs/terminology.md`.
