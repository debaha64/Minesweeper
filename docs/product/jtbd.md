# Задачи пользователя (JTBD)

Статус: draft.

## Назначение

Задачи пользователя, ради которых существует продукт.

## Основные задачи

1. Когда у пользователя есть поле Minesweeper и выбранная клетка, он хочет передать их локальной CLI-команде, чтобы получить число соседних мин.
2. Когда пользователь ошибается в координатах или формате поля, он хочет получить предсказуемую диагностическую ошибку без частичного результата.

## Контекст

1. Поле задаётся позиционными CLI-аргументами: одна строка поля на аргумент.
2. Координаты передаются через `--row` и `--column` и считаются от нуля.
3. Постоянное хранение, сеть и внешние runtime-зависимости отсутствуют.

## Критерии полезности

1. Валидный пример печатает ровно `1` и завершается с exit code `0`.
2. Invalid board или invalid coordinates завершаются с exit code `2`, пустым stdout и кратким stderr.
3. Существующая команда `--smoke` сохраняет поведение.

## Не входит

1. Постоянное хранение игрового поля.
2. Интерактивный игровой цикл или графический интерфейс.
3. Сеть, внешние сервисы и сторонние runtime-зависимости.
4. Реализация до отдельного решения владельца.
