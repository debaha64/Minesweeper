# Краткое описание продукта

## Назначение

Краткое актуальное описание продукта.

## Продукт

Minesweeper

## Пользователь

Пользователь локальной CLI-программы, которому нужно определить число мин вокруг выбранной клетки.

## Ценность

Получить детерминированный результат подсчёта соседних мин одной локальной командой без постоянного хранения и внешних сервисов.

## Основной сценарий

Пользователь передаёт zero-based координаты и непустое прямоугольное поле позиционными аргументами команды `count`, получает одно целое число в stdout.

## Границы первой версии

Команда `count` поверх существующей функции `adjacent_mines`; символы поля только `*` и `.`, сохранение `--smoke`, Python standard library, явные ошибки доски и координат с exit code `2`.

## Ключевые решения

1. Поле существует только во время выполнения команды и передаётся отдельными строками после опций координат.
2. Координаты имеют zero-based семантику.
3. Успех печатает ровно одну строку с числом и оставляет stderr пустым.
4. Invalid board или invalid coordinates дают exit code `2`, пустой stdout и краткое сообщение в stderr.
5. Изменяемые product paths будущей реализации ограничены `README.md`, `src/minesweeper.py` и `tests/test_minesweeper.py`.
