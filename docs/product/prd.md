# Требования к продукту

Статус: draft.

## Назначение

Требования, ограничения и границы продукта.

## Цель продукта

Добавить к существующему локальному Minesweeper baseline детерминированную CLI-команду подсчёта мин вокруг выбранной клетки.

## Пользователи

1. Пользователь локальной CLI-программы, имеющий поле Minesweeper и координаты выбранной клетки.

## Функциональные требования

1. CLI предоставляет команду:
   `python3 src/minesweeper.py count --row <row> --column <column> <board-row> [<board-row> ...]`.
2. `row` и `column` являются zero-based координатами выбранной клетки.
3. Поле состоит из одной или нескольких непустых строк одинаковой длины.
4. Допустимые символы поля — только `*` и `.`.
5. Валидная команда печатает в stdout единственную строку с числом соседних мин, оставляет stderr пустым и возвращает exit code `0`.
6. Invalid coordinates или invalid board оставляют stdout пустым, печатают краткое сообщение в stderr и возвращают exit code `2`.
7. Команда использует существующую функцию `adjacent_mines`.
8. Существующее поведение `python3 src/minesweeper.py --smoke` сохраняется.
9. Команда и валидный пример документируются в root `README.md` только после implementation gate.

## Нефункциональные требования

1. Используется только Python standard library.
2. Результат CLI детерминирован для одинаковых аргументов.
3. Постоянное хранение, сеть и внешние runtime-зависимости отсутствуют.
4. Технический PASS не является продуктовой приёмкой.

## Ограничения

1. Изменяемые product paths ограничены `README.md`, `src/minesweeper.py` и `tests/test_minesweeper.py`.
2. До отдельного implementation gate эти product paths не изменяются.
3. Discovery не разрешает Git, переход режима или внешние действия.

## Не входит

1. Изменение формата или места хранения данных: хранение отсутствует.
2. Полный игровой CLI, открытие клеток, флаги или генерация поля.
3. Release/tag, GitHub-действия и публикация.
4. Автоматическая продуктовая приёмка.
