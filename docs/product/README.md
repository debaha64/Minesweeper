# docs/product/

Назначение: продуктовый слой пакета документации продукта.

## Артефакты

- `product-brief.md` — краткое описание продукта.
- `product-passport.md` — паспорт продукта и текущее состояние.
- `prd.md` — требования и границы продукта.
- `jtbd.md` — задачи пользователя и ожидаемые результаты.
- `dods.md` — критерии готовности продукта и результата.

## Граница

- Здесь хранится смысл продукта.
- Процедуры работы с документами находятся в `sops/`.
- Архитектурные решения находятся в `docs/architecture/`.
- Технические сведения находятся в `docs/technical/`.
