# docs/

Назначение: пакет документации продукта. `docs/` хранит устойчивый смысл продукта, архитектуры, технических фактов, пользовательского слоя и терминологии.

## Артефакты

- `product/` — продуктовый смысл, требования, DoDs и owner-visible ограничения.
- `architecture/` — архитектурная структура, модель предметной области и контракты.
- `technical/` — технические сведения запуска, форматов, качества, надёжности, безопасности и проверок.
- `user/` — пользовательский слой, первый старт и режимы работы.
- `terminology/` — рабочий словарь Product Unit.

## Граница

- `docs/` объясняет смысл, состояние, модель, факты и ссылки на связанные процедуры.
- `sops/` хранит процедуры, правила, запреты, проверки и процессы.
- `templates/` хранит формы артефактов и записей.
- README каталога является кратким индексом: назначение, файлы, граница и связанные каталоги.

## Связанные каталоги

- [../sops/](../sops/README.md) — процедуры работы.
- [../templates/](../templates/README.md) — формы документов и записей.
