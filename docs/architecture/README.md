# docs/architecture/

Назначение: архитектурный слой пакета документации продукта.

## Артефакты

- `architecture.md` — архитектурная структура и ключевые решения.
- `domain-model.md` — модель предметной области.
- `input-output-contract.md` — внешние и внутренние контракты, если применимо.

## Граница

- Архитектура описывает структуру и решения.
- Процедуры работы с архитектурой находятся в `sops/`.
- Технические сведения запуска, форматов и среды находятся в `docs/technical/`.
