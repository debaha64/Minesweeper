# Модель предметной области

Статус: справочный

## Основные сущности

- Product Unit: текущая файловая обвязка продукта.
- Продуктовая часть: будущий прикладной код и связанные тесты.
- ROAD: стратегический маршрут.
- BACK: исполняемая задача в горизонте.
- PLAN: активный план прохода.
- Решение владельца: явное решение владельца.
- Технический PASS: результат механических проверок, не продуктовая приёмка.

## Границы

1. Product Unit хранит документы, процедуры, планы, журналы, шаблоны и проверки.
2. Продуктовая часть появляется только после завершения discovery и получения решения владельца.
3. `src/` и `tests/` остаются граничными слоями до PLAN фазы `implementation`.
4. Выпуск, тег, GitHub-действия и продуктовая приёмка выполняются только по отдельным решениям владельца.
