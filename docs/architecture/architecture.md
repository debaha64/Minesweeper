# Архитектура

Статус: active.

Product Unit состоит из системного реестра, документов смысла, планового контура, журналов, процедур, шаблонов, механических проверок и будущих кодовых слоёв.

## Контракт

1. `SYSTEM.md` задаёт системный контракт.
2. `plans/` задаёт `ROAD -> BACK -> PLAN`.
3. `logs/` фиксирует решения, изменения, качество, риски и сессии.
4. `tools/bp_check.py` проверяет текущую фазу и состояние Product Unit.
5. `src/` и `tests/` остаются граничными слоями до решения владельца и PLAN фазы `implementation`.
