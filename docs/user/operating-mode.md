# Операционный режим

Текущий устойчивый режим источника истины хранится в поле `SOT_MODE` файла `AGENTS.md`.

## Поддерживаемые режимы

1. `sot_files` — работа только с файловой поверхностью; Git не требуется и не проверяется.
2. `sot_git` — локальный Git repository с рабочей ветвью, чистым деревом и без remote.
3. `sot_github` — подготовленная локальная рабочая копия ожидаемого GitHub repository; дополнительно используется поле `SOT_GITHUB_REPOSITORY` в форме `owner/repository`.

Для `sot_github` authentication, GitHub metadata, fetch и подготовка `origin/HEAD` выполняются внешним preflight. `bp_check.py` использует только уже существующее локальное состояние, не обращается к сети и ничего не исправляет автоматически.

## Границы

Режим источника истины не разрешает реализацию, переход режима, GitHub write, продуктовую приёмку или выпуск. Эти действия имеют отдельные решения владельца и нормативные процедуры.

Атомарного перехода `sot_files -> sot_github` нет, а обратные переходы из `sot_github` в `0.5.0` не реализованы. Полный контракт находится в [sops/sot.md](../../sops/sot.md).
