# Пользовательская документация

Этот раздел помогает начать работу с Product Unit и понять границы трёх режимов источника истины.

## Документы

1. [Первый старт](first-start.md) — что подготовить перед началом работы.
2. [Операционный режим](operating-mode.md) — различия `sot_files`, `sot_git` и `sot_github`.
3. [Подготовка репозитория GitHub](github-repository-preparation.md) — внешний preflight и локальная граница `sot_github`.

Пошаговые нормативные процедуры находятся в [sops/](../../sops/README.md), а технические сведения — в [docs/technical/](../technical/README.md).

Технический PASS не является продуктовой приёмкой и сам по себе не разрешает выпуск или GitHub-действия.
