# Форматы данных

## ID стартовой обвязки

Стартовая обвязка Product Unit использует нейтральные стартовые ID.

## ID продукта

Новая Product Unit использует нейтральные ID:

- `ROAD-000001`;
- `BACK-000001`;
- `PLAN-000001-product-discovery.md`.

Проверки определяют фазу по `plans/backlog.md` и активному PLAN. Идентификаторы истории исходной обвязки или рабочей папки не являются частью стартового состояния.
