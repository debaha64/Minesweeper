# docs/technical/

Назначение: технический слой пакета документации продукта.

## Артефакты

- `artifact-lifecycle.md` — смысл жизненного цикла артефактов.
- `data-formats.md` — форматы таблиц, журналов и примеров.
- `git.md` — техническая граница Git и SoT.
- `language-support.md` — текущий язык и отложенные языковые профили.
- `phase-gates.md` — смысл фазовых точек контроля.
- `quality.md` — техническое качество и свидетельства.
- `reliability.md` — надёжность и восстановимость.
- `sdlc.md` — модель Конвейера разработки (SDLC).
- `security.md` — безопасность, секреты и внешние слои.
- `system-style.md` — русский технический стиль.
- `task-flow.md` — модель потока задач.
- `testing.md` — стратегия технической проверки.

## Граница

- `docs/technical/` хранит технические факты, ограничения, форматы, модели проверки и ссылки на SOP.
- Архитектурная структура, модель предметной области и контракты находятся в `docs/architecture/`.
- Исполняемые инструкции, запреты, проверки и чистое завершение (`clean-exit`) находятся в `sops/`.
- Procedural markers в technical files не расширяют SOP: порядок действий остаётся в `sops/`.
