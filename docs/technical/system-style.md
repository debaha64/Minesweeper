# Стиль системы

## Назначение

Документ объясняет смысл русского технического стиля Product Unit и связь со слоями терминологии.

## Смысл

1. Человекочитаемые артефакты ведутся по-русски.
2. Для одного смысла используется один канонический термин.
3. Английские формы сохраняются для путей, команд, идентификаторов, machine values, check-id и официальных технических имён.
4. История не переписывается ради стиля.
