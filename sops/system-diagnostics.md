# Диагностика системы

## Назначение

Диагностика показывает состояние Product Unit без автоматического исправления.

## SoT/Git

Диагностика один раз разбирает `SOT_MODE` из `AGENTS.md` и условный `SOT_GITHUB_REPOSITORY` только для `sot_github`.

В `sot_files`:

1. путь `.git` не читается, не классифицируется и не проверяется;
2. Git CLI не вызывается;
3. состояние контролируется файловыми средствами вне `.git`.

В `sot_git` проверяются:

1. валидность корня локального репозитория;
2. существование базового коммита;
3. отсутствие remote;
4. рабочая ветка и чистота дерева по правилам текущей проверки.

В `sot_github` дополнительно проверяются единственный `origin`, URL/repository identity, upstream, existing remote refs, symbolic `origin/HEAD` и допустимая divergence. Диагностика не вызывает сеть, не выполняет fetch и не исправляет состояние.

Подтверждение запуска shell-команды не заменяет решение владельца.
