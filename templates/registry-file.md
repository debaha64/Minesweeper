# Реестровый файл

Статус: markdown registry.

## Назначение

Описать, какой реестр ведётся и какое системное решение он поддерживает.

## Владелец смысла

Указать `owner:human`, `owner:agent`, `owner:tools` или `owner:harness-engineering`.

## Область уникальности ID

Указать, где ID должен быть уникален: файл, слой, домен, версия или весь проект.

## Формат записи

Сослаться на `templates/registry-item.md` или локальный формат строки.

## Правила изменения

1. Новые записи добавляются по выбранному формату.
2. Исторические записи не переписываются ради косметики.
3. Если меняется смысл реестра, проверить `SYSTEM.md`, `templates/README.md`, связанные SOP и журналы.

## Связь с проверками

Указать ручную или механическую проверку, которая использует реестр.

Машиночитаемый JSON/YAML-реестр в этом проходе не создаётся.
