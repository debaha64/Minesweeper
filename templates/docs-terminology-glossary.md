# Глоссарий

Глоссарий — краткий реестр устойчивых терминов Product Unit. Правила ведения находятся в `sops/terminology.md`.

## Системные термины

- `Решение владельца` — явный выбор человека; технический PASS его не заменяет.
- `Управление проектом` — локальный контур `ROAD -> BACK -> PLAN` и связанные журналы.
- `Источник истины (SoT)` — текущий режим владения состоянием.
- `sot_files`, `sot_git`, `sot_github` — три поддерживаемых режима SoT.
- `SOT_GITHUB_REPOSITORY` — условное repository field только для `sot_github`.
- `Product Unit` — самостоятельная продуктовая единица.
- `DoD` — критерии готовности проверяемого результата.
- `Чистое завершение (clean-exit)` — завершение прохода с проверками и следующим шагом.
