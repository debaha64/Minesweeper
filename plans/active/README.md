# Активные планы

Статус: рабочий артефакт

Здесь лежит 0 или 1 активный `PLAN-<id>-<slug>.md`.

Если активный PLAN есть, агент продолжает его. Если активного PLAN нет, агент читает [../roadmap.md](../roadmap.md) и [../backlog.md](../backlog.md), затем берёт следующую задачу активного этапа.

Если найден конфликт между запросом владельца и активным PLAN, агент останавливается и фиксирует блокер.
