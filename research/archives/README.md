# Архивы исследований

## Назначение

`research/archives/` хранит архивы завершённых research-доменов Product Unit.

## Правило Архивов

1. Архив создаётся только после closeout исследовательского домена.
2. Архив не перезаписывается.
3. Номер завершённого исследования не переиспользуется.
4. Распакованный домен удаляется или переносится только по отдельному разрешённому маршруту.
5. Этот файл является индексом архивов, а не журналом решений владельца.

## Индекс

Архивы отсутствуют.
